# Jev retrieval evaluation

The current [two-stage evaluation](two-stage/README.md) covers MuSiQue and 2Wiki, 1,000 questions each, with an average Recall@5 of **86.07%**. It includes the frozen recipe, baseline comparisons, latency assumptions and offline reproduction commands.

![Quality and latency](../../docs/assets/evaluation/quality-latency.png)

See the [reranking guide](../../docs/guides/reranking.md) to enable Jev with the base installation. The earlier [500-row relation-only experiment](historical-500.md) and its source artifacts remain available for traceability; they are not the current default Jev behavior.
